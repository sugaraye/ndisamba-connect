🚀 NDI SAMBA CONNECT - TAILWINDCSS DEMO (v4)

📦 FICHIERS :
- index.html : Page d’accueil de démonstration
- input.css : Source Tailwind (à compiler)
- tailwind.config.js : Configuration du thème
- output.css : Généré automatiquement

⚙️ COMMANDES :
1️⃣ Ouvre PowerShell dans ce dossier
2️⃣ Exécute :
   .\tailwindcss.exe -i ./input.css -o ./output.css --watch
3️⃣ Ouvre index.html dans ton navigateur

💡 CONSEILS :
- Personnalise les couleurs dans tailwind.config.js
- Ajoute d’autres sections (actualités, formations, etc.)
- output.css est régénéré automatiquement à chaque sauvegarde.
